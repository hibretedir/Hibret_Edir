How a New Family Joins Hibret Edir

Board handout — automated waiting list & membership pipeline · June 2026

Waiting list → Invite → Application → Board review → PayPal $200 → Active member

The seven steps

  1. Waiting list — Families sign up on the public website. They appear in queue order (first applied, first invited when a slot opens).
    Admin → Approval → Waiting List → All
  2. Send invitation — When we have an open slot (cap 200 active), click Send Invitation → on eligible rows at the top of the list. They receive an email to apply.
    Waiting List → All (invite button) or Invited tab
  3. Application — The family completes the full form and uploads California ID. Status moves to In Progress.
    Waiting List → In Progress · Applications → Pending
  4. Board review — Open Review and confirm: name matches waiting list, all fields complete, ID acceptable. Save progress if needed.
    Applications → Pending → Review
  5. Approve & send invoice — When all three checks pass, click Approve & Send Invoice. PayPal emails the $200 registration fee. We do not charge before vetting.
    Application review modal
  6. Payment — Applicant pays via PayPal. The system adds them as an active member automatically (sync runs 9 AM & 6 PM Pacific). For Zelle/BofA, use Mark Registration Paid.
    Applications → Awaiting Payment
  7. Portal access — New member sets up phone + PIN on the member portal and receives event invoices like other members.
    hibretedir.com/portal
Board responsibility: Invite the right people, review carefully, approve when vetted. The platform handles queue order, PayPal invoices, payment tracking, member records, and audit logging.
